# Порівняння моделей v1 і v2

Обидві моделі оцінено однаковим конвеєром (Resize 256 → CenterCrop 224, AMP FP16) на тих самих фото.
**v2** — фінальний режим передбачення: логіти + log(prior навчального потоку). Цей режим обрано на валідації (PlantVillage val і PlantDoc val, `results/v2/potato_healthy_check.json`), не на test. Для довідки наведено й v2 зі звичайними логітами.

**PlantDoc test без витоку (n=107)** — основний результат: з 114 фото виключено 7, копії яких (той самий знімок, кроп або інше стиснення) потрапили в навчання v2 (`data/plantdoc_test_leaks.json`, метод — `scripts/leak_check.py` + ручний перегляд). Повний test (114) наведено для довідки.

## ⚠️ PlantDoc test малий (107 фото без витоку)

- 95 % bootstrap-інтервал top-1: v1 [20.6; 38.3], v2 [49.5; 68.2]; macro-F1: v1 [17.2; 31.5], v2 [47.5; 65.2].
- Парне порівняння на тих самих фото: лише v2 вірно — 34, лише v1 вірно — 2; точний тест Мак-Немара p = 1.9e-08.
- Macro-F1 рахується по 13 класах, у більшості класів у test лише 6–11 фото, тож macro-F1 тут особливо шумний.
- Витік: 7 фото test мали копію в навчанні v2 (5 — у pd_train, 2 — у pd_val, за якою обирали епоху). Перша перевірка (MD5 + dHash ≤ 4) їх не знайшла, бо це кропи/перестиснення; знайдено ембедингами ImageNet-моделі й підтверджено вручну.
- Шум у мітках: 11 точних/майже точних пар «train ↔ test» виключено ще до навчання; у 7 з них мітки різні (зачіпає 6 фото test). Серед 7 фото з витоком ще у 2 мітки різні. Неоднозначність міток обмежує досяжну точність на test.
- Епоху v2 обрано за PlantDoc val (224 фото); test у навчанні й виборі моделі не використано.
